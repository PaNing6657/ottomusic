## 修复：游戏音符判定后卡住（game.js）+ 编辑器滚动卡死（editor.html）

**游戏卡住根因**（`public/js/game.js`）：
1. `hitLane` 命中后推进游标 `noteIdx = max(noteIdx, i+1)`，会跳过中间未处理音符 → 被跳过音符永不被 Miss 检测/渲染循环处理，卡在屏幕上。**修复**：游标只由 Miss 检测推进（`if (n._done) noteIdx++`），hitLane 只标记状态
2. Miss 后音符不在渲染范围 → 无移除逻辑。**修复**：统一 `removeNoteEl(n)`（加 .hit 动画 + opacity 0 + 260ms 后 remove），Miss/tap 命中/hold 完成/hold 断开四处调用
3. hold 状态用字符串区分：'hold'(按住中不移除) / 'tap' / 'miss' / 'complete' / 'broken'；hold 尾条固定长度=(endTime-n.time)*pxPerMs*1000，命中后由 holds 循环缩短；hold 命中加 .hold-active class 箭头淡出
4. 额外修复：编辑器 editor.html **缺少 `<div id="gridLayer">` 元素** → editor.js `els.gridLayer.replaceChildren()` 抛 null 错误，初始化中断导致 content 宽度未撑开、滚动条只有 110px 卡死。已补回元素

**验证**：headless Chrome（puppeteer-core + 本机 Chrome）实测 MISS/命中/BREAK/密集谱面四路径，音符残留均为 0、计分正常、无 JS 错误。经验：`node -e` 不继承 NODE_PATH，加载 puppeteer 需写文件运行。

## 下落式箭头音乐游戏（Node.js 前后端项目）

**音频**：固定使用 `8月20日.wav`（PCM 44.1kHz/16bit/立体声，时长 143.24s，25.3MB），浏览器原生可播，无需转码。

**项目结构**（根目录 D:\ottohub\ottomusic）：
- `server/index.js` — Express 后端：`/api/audio`（Range 流式音频）、`/api/audio/info`（WAV 头解析时长）、`/api/maps` CRUD（JSON 存储于 data/maps/）
- `public/editor.html` + `js/editor.js` + `css/editor.css` — 谱面编辑器（核心铺页）：波形可视化(canvas 峰值)、四轨道(↑↓←→ 映射 WASD/方向键)、点击放置/拖动/右键删除/双击 tap↔hold、BPM 网格吸附(1/1~1/32)、自动 BPM 检测(能量自相关)、播放头跟随滚动、Ctrl+S 保存、试玩跳转
- `public/game.html` + `js/game.js` + `css/game.css` — 游戏端：下落箭头、判定窗口 Perfect±45ms/Great±90ms/Good±135ms、hold 长按、计分连击准确率、结算评级(SS~D)
- `public/index.html` — 入口页
- 谱面格式：`{id, name, bpm, offset, notes:[{time,lane,type:'tap'|'hold',endTime?}]}`，lane 0=↑ 1=↓ 2=← 3=→

**启动**：`node server/index.js` → http://localhost:3000（端口 3000）

**关键经验**：
- 音频拖动播放必须支持 HTTP Range（express 手动处理 `Content-Range`）
- 沙箱/杀软会把 `fs.unlinkSync` 包装成回收站操作并抛错——DELETE 需容错（文件已不在则视为成功）
- 编辑器横向布局用 `scroll-area{display:flex}` + 左标签列 `position:sticky;left:0`，内容区 `flex-shrink:0`
- WAV 时长 = dataChunkSize / (sampleRate × channels × bytesPerSample)
- BPM 自动检测用单声道能量帧自相关，倍频(0.5x/2x)候选取最接近 120 的
